Project name: FitLog: Workout Library

Short description: FitLog is a dark-themed workout app for the gym. You can browse a library of exercises, open each one to see equipment, sets, reps and step-by-step instructions, and build a daily plan of up to five lifts. You can also save workouts for later. Totals for exercises, minutes and calories update live for whichever list you're viewing.

Technologies used:

Next.js
React
TypeScript
Tailwind CSS
Sonner for pop-up notifications

5 key features:

Workout library: A grid of exercise cards showing muscle-group tags, equipment, duration, calories and rating.
Workout detail pages: Each exercise has its own page with equipment, difficulty, sets, reps, duration, calories and numbered instructions.
Today's Plan with a 5-lift limit: You can add up to five exercises to today's plan, mark them as done and remove them. A warning appears when you hit the limit.
Saved list: You can bookmark workouts for later in a separate tab, and switch between Today's Plan and Saved.
Live stats and sorting: The Exercises, Minutes and Calories totals recalculate for the tab you're on, and you can sort either list by duration and other options. Counts in the navbar show how many items are in each list.
